CLIP STUDIO - EDITOR 2.2 - GPU

1. Python 3.12 de 64 bits debe estar instalado.
2. FFmpeg: en PowerShell, winget install --id Gyan.FFmpeg -e
3. Extrae TODO el ZIP en una carpeta.
4. Haz doble clic en INICIAR_WINDOWS.bat.
   Instalara las dependencias. Deja abierta la ventana mientras usas la app.

ANALIZAR LOCAL CON GPU - SIN CLAVE NI PAGO DE API
1. Actualiza el driver de NVIDIA.
2. Ejecuta INSTALAR_GPU_WINDOWS.bat una vez. Instala Ollama y descarga
   qwen2.5:7b (~4,7 GB). Debe decir GPU VERIFICADA.
3. Opcional: INSTALAR_TRANSCRIPCION_GPU_WINDOWS.bat acelera tambien el audio.
   Descarga PyTorch CUDA 12.8 y Whisper; realiza una prueba CUDA real.
4. Abre INICIAR_WINDOWS y selecciona Local GPU.
5. Pulsa Comprobar GPU. Solo se considera acelerado si Ollama informa memoria GPU.
6. Activa Transcribir tambien con GPU si instalaste ese componente.

La GPU se usa por turnos para transcribir y analizar; asi los dos modelos
no se mantienen cargados a la vez en tus 8 GB de VRAM.
Se necesita Internet para instalar y descargar modelos la primera vez.
No se ha medido el rendimiento en tu RTX; prueba primero con un video corto.
Si Ollama no detecta GPU, actualiza su version y el driver NVIDIA.

API EN NUBE (OPCIONAL)
La opcion en nube necesita una clave y saldo de OpenAI. El modo Local GPU
no la necesita ni genera cargos de API. No compartas claves por chat.

REUTILIZAR
Conserva la carpeta data de la version anterior y copiala a esta version,
con la app cerrada. Reutilizar un video guardado permite recuperar la
transcripcion completa de tu intento anterior sin esperar otra vez por ella.

MODO LOCAL OPCIONAL
Ejecuta INSTALAR_IA_LOCAL.bat para instalar el motor local.
Qwen 7B en CPU puede ser muy lento; no es el modo recomendado para rapidez.

EDITAR
Hay cuatro pestanas: Titulo, Subtitulos, Logo y Encuadre.
Puedes arrastrar las capas en el video, cambiar posicion y tamano,
fuentes, colores y contorno de subtitulos. La descarga siempre esta abajo.
Al reproducir se respetan los tiempos; Ver capas al editar permite acomodarlas en pausa.
Los titulos permanecen durante todo el clip y no superan dos lineas al exportar.

LOGOS
En Logo, abre Cargar desde mis archivos. Usa PNG transparente si puedes.
Ajusta ancho, posicion y el intervalo. Desde 2 y Hasta vacio significa
segundo 2 hasta el final. Desde 10 Hasta 20 significa solo esos segundos.
Los tiempos son relativos al clip, no al video original.

ACTUALIZAR
Conserva tu carpeta anterior y extrae el ZIP nuevo en otra carpeta.
Puedes copiar la carpeta data anterior para conservar modelos y logos,
con ambas apps cerradas. No copies la .venv anterior.

Cierra con Ctrl+C en la ventana negra. No publiques este servidor en Internet:
esta version personal no tiene login.

Cobertura fija: al menos 75% del video, sin contar dos veces solapamientos.
La cantidad de clips se calcula segun el rango. Todos tienen titulos; Mayor potencial marca los destacados. Logos: ancho hasta 100%.
Al actualizar conserva data y .venv, y copia tambien coverage.py.
